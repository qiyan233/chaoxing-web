# 控制台按钮功能验收（2026-10-09）

| 页面 / 控件 | 实际效果 | 验证方式 |
| --- | --- | --- |
| 新建任务、新建课程任务 | 进入账号选择页，识别已有排队/运行任务，再进入课程页选择和提交 | 页面访问、浏览器账号列表、任务 API 持久化与调度调用 |
| 账号添加、重新登录、删除 | 保存账号、调用登录服务并更新状态、从数据库删除账号 | 临时数据库 CRUD；外部登录服务模拟 |
| 课程刷新、筛选、全选、单选 | 拉取课程接口（强制刷新传 refresh=true）、过滤列表、修改课程选择 | 服务调用参数、前端选择逻辑 |
| 模式选择、启动、取消弹窗 | 提交实际 course_ids/speed/mode/jobs=1 参数并跳转任务详情；关闭取消弹窗 | 前端请求参数、后台保存、浏览器弹窗开关与 Escape |
| 任务取消 | 调用取消接口，刷新状态；不可取消时展示拒绝原因 | 临时任务真实变为 cancelled；业务拒绝前端回归 |
| 任务日志、查看全部日志 | 独立日志页读取完整数据库日志，支持级别/内容/账号筛选和分页 | 数据库权限/分页测试；浏览器读取 105 条日志并翻页、筛选 |
| 日志任务编号 | 定位相应任务详情的日志区域 | 实际任务详情地址和锚点 |
| 用户开通、状态、重置密码、删除 | 修改平台用户数据；新密码登录成功、旧密码拒绝 | 临时数据库和真实认证 API |
| 用户绑定、解绑账号 | 修改学习通账号归属 | API 读取确认实际 user_id 变化 |
| 题库与代理配置保存 | 调用设置接口，数据库持久化，供后续请求/任务读取 | POST/GET 往返校验、参数校验失败回归 |
| 代理添加、复测、启用、禁用、批量操作 | 调用对应代理服务接口并更新/删除记录 | 临时代理 CRUD；连通性结果模拟；前端拒绝路径 |
| 检查更新、在线更新、重启 | 调用已有更新/重启服务；有未提交改动时禁止更新；失败不安排刷新 | 服务实现核对、前端请求及拒绝回归；未执行真实 Git 更新或网页重启 |
| 导航、搜索、趋势范围、任务队列、主题、账户菜单 | 真实页面导航、任务过滤、统计时间切换、队列切换、主题持久化、菜单开关 | 浏览器交互和数据展示 |
| 退出登录 | 成功清除会话后跳转；失败保留当前页并显示错误 | 前端成功/失败回归、认证 API |

## 修复与移除

- 新建任务不再用账号管理列表充当创建向导；“查看全部日志”不再跳到任务列表。
- 空选择、无效或刷新后的旧课程选择不能启动全部课程；提交明确传所选课程 ID。
- HTTP 错误、网络失败和 HTTP 200 中的 status=false 都阻止后续成功提示/跳转；错误同时显示在页面上。
- 配置尚未成功加载时禁止保存，更新状态尚未检查时不会显示“已是最新”。
- 移除尚未实现的通知推送、代理自动失败切换、锁定章节回退重试/询问入口；保留兼容 API 字段并在文档注明限制。
- 消息图标改为有实际目的的日志入口；串行模式入口定位真实运行配置。
- 修复弹窗 Escape 事件未冒泡到 window 的问题；移除 Alpine init 与 x-init 重复初始化。

## 验收结果与范围

`python -m unittest discover -s tests -t . -q`：67 项测试通过（91.236 秒）。

`node tests/ui_actions.cjs`：19 条管理操作拒绝路径，以及任务选择、取消、重启失败、退出、嵌套动作错误传播等检查通过。

Python 语法、Jinja 模板与渲染后的 JavaScript 语法检查通过；浏览器验证无控制台错误。最终日志筛选读取到 8 条真实警告记录，上一页/下一页根据结果数正确禁用。

回归使用临时数据库；超星登录/课程查询及代理连通性使用模拟返回，验证接口调用、参数和本地数据效果，未宣称验证外部平台最终结果。没有提交真实学习任务，没有修改现有账号、密码、配置或代理数据。实际外部结果仍取决于有效凭据、网络与第三方服务状态。
